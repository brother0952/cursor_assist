# 国家统计局数据发布页面爬虫

这个Python爬虫可以自动下载国家统计局数据发布页面（https://www.stats.gov.cn/sj/zxfb/）的所有文章和附件。

## 功能特点

- 自动爬取国家统计局数据发布页面的所有文章
- 根据文章标题创建文件夹并保存HTML文件
- 自动下载文章中的附件（PDF、DOC、XLS等格式）
- 支持多页爬取
- **断点续传功能**：检测已下载的文章并跳过，避免重复下载
- **失败重试功能**：自动重试之前失败的下载
- 包含错误处理和日志记录
- 添加请求延迟，避免对服务器造成压力
- 详细的下载统计信息

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

1. 直接运行脚本：
```bash
python stats_crawler.py
```

2. 或者运行增强版（推荐）：
```bash
python stats_crawler_enhanced.py
```

3. 默认会爬取前5页的内容，可以在代码中修改 `max_pages` 参数

## 输出结构

下载的文件会保存在 `downloaded_articles` 目录下，每个文章会创建一个以文章标题命名的文件夹：

```
downloaded_articles/
├── download_record.json          # 下载记录文件
├── 文章标题1/
│   ├── 文章标题1.html
│   ├── article_info.json        # 文章详细信息（增强版）
│   ├── 附件1.pdf
│   └── 附件2.xlsx
├── 文章标题2/
│   ├── 文章标题2.html
│   ├── article_info.json
│   └── 附件3.doc
└── ...
```

## 新增功能说明

### 断点续传功能
- 爬虫会检查文章是否已下载，如果已存在则跳过
- 通过 `download_record.json` 文件记录每篇文章的下载状态
- 支持多次运行，只下载新文章或之前失败的文章

### 失败重试功能
- 自动检测之前失败的下载并重试
- 每次运行时会先重试失败的下载，再下载新文章
- 详细的统计信息显示跳过、成功、失败的文章数量

### 下载记录文件
`download_record.json` 文件包含：
- 文章URL
- 文章标题
- 下载状态（success/failed）
- 下载时间

## 注意事项

1. 请遵守网站的robots.txt规则和使用条款
2. 建议在非高峰时段运行，避免对服务器造成压力
3. 脚本已添加2-3秒的请求延迟，可以根据需要调整
4. 如果遇到网络问题，脚本会自动重试并记录错误
5. 下载记录文件会自动保存，支持断点续传

## 自定义配置

可以在 `StatsCrawler` 类中修改以下参数：

- `base_url`: 目标网站的基础URL
- `output_dir`: 输出目录
- `max_pages`: 最大爬取页数
- `retry_failed`: 是否重试失败的下载（默认True）
- 请求延迟时间（在 `crawl_all_articles` 方法中的 `time.sleep()`）

## 错误处理

脚本包含完整的错误处理机制：
- 网络连接错误
- 文件下载失败
- 文件名非法字符处理
- 详细的日志记录
- 下载状态跟踪

如果遇到问题，请查看控制台输出的日志信息或 `crawler.log` 文件。

## 统计信息

运行完成后会显示详细的统计信息：
- 总文章数
- 跳过文章数（已存在）
- 成功下载数
- 下载失败数
- 附件下载统计
