# 视频实时FFT分析工具

此工具可以打开摄像头，让用户通过鼠标点击选择感兴趣区域（ROI），并对该区域的平均亮度进行短时傅里叶变换（STFT）分析，实时显示视频画面和频谱图。

## 功能特点

- 实时视频捕获
- 鼠标点击选择ROI中心点（默认半径30像素）
- 对ROI区域的平均亮度计算短时傅里叶变换
- 实时显示视频画面和频谱图

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

有两种分析模式可供选择：

### 1. STFT频谱图模式 (video_fft_analyzer.py)

```bash
python video_fft_analyzer.py
```

运行后会打开两个窗口：
1. OpenCV窗口（'Video Feed'）- 显示实时视频画面
2. Matplotlib窗口 - 显示视频画面和频谱图

在'Video Feed'窗口中点击任意位置设置ROI中心点，红色圆圈标记了ROI区域。程序会对该区域内像素的平均亮度进行STFT分析，并在频谱图中显示结果。

### 2. FFT谐波分析模式 (harmonic_analyzer.py)

```bash
python harmonic_analyzer.py
```

此模式专注于实时观察谐波特性：
- 在视频画面上直接显示频率谱曲线
- 标记明显的谐波峰值
- 显示对应的频率值

## 操作说明

- 在视频窗口中点击任意位置设置ROI中心点
- 红色圆圈表示ROI区域（半径30像素）
- 左侧显示实时视频画面
- 右侧显示频谱图/频率曲线
- 关闭OpenCV窗口或按'q'键可退出程序

## 注意事项

- 需要可用的摄像头设备
- 确保环境光线适中以获得更好的分析效果
- 若无scipy库，STFT功能将受限
